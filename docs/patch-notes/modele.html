Un geste retour plus calme

La page ne glisse plus sous vos doigts. Une pastille sort du bord et se remplit ; au seuil, le trackpad donne un léger retour. Relâchez : la page précédente apparaît en fondu.

macOS · Linux

Des icônes lisibles sur toutes les couleurs

La barre d’adresse prend la couleur de la page. Sur les teintes moyennes, les icônes passent désormais en blanc ou en noir, selon ce qui contraste le mieux.

Essayez : choisissez une couleur de page.
